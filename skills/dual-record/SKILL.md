# 双录（销售行为可回溯）准备与检查

适用于向自然人销售**保险期间超过一年**的人身险，或**保证续保**的短期人身险。
排除：电话销售、互联网保险、自助终端投保及特定豁免产品。

> ⚠️ **各地细则不同，录制前必须确认展业地规则**。山西、新疆、东莞、
> 福建等地要求存在差异。不确定时用联网搜索核对当地金融监管局最新通知。

## 一、录前准备清单

**人员**
- [ ] 销售人员本人到场（须为持证本人，不得替代）
- [ ] 投保人到场；被保险人到场（如非同一人）

**证件**
- [ ] 销售人员有效身份证明
- [ ] 投保人有效身份证明
- [ ] 被保险人有效身份证明

**资料**
- [ ] 投保提示书
- [ ] 产品条款
- [ ] 产品说明书（如有）
- [ ] 免除保险人责任条款的**书面说明**

**设备**
- [ ] 录制设备电量/存储充足
- [ ] 视频中能显示**录制时间**
- [ ] 确认录制**不得剪辑**（东莞等地明确要求）

## 二、五个必备环节（不可遗漏）

### 环节 1：身份证明

> 话术示例：
> "您好，我是 XX 保险公司的销售人员 XXX，这是我的有效身份证明，
> 我所属机构是 XX 保险公司。请您出示一下您的有效身份证明。"

**要点**：出示证件 + 告知所属机构名称。投保人、被保险人都要出示。

### 环节 2：资料展示

> 话术示例：
> "现在向您出示以下文件：投保提示书、产品条款、产品说明书，
> 以及免除保险人责任条款的书面说明。请您过目。"

**要点**：文件须在镜头内**可见**，不能只口头提及。

### 环节 3：产品说明（核心，最易遗漏）

必须说明**全部**以下要素：

| 要素 | 说明 |
|---|---|
| 承保机构名称 | 明确是保险产品 |
| 保险责任 | 保什么 |
| **责任免除** | **不保什么** |
| 投保范围 | 谁能保 |
| 保险期间 | 保多久 |
| 交费方式 / 金额 / 期间 | 交多少、交几年 |
| 保单利益 | 能拿到什么 |
| **犹豫期** | 起算时间、天数、期内权利 |
| **犹豫期后退保** | 需扣除的费用 + 退保金计算方法 |

> ⚠️ 关键提示：必须明确告知"所购买的是**保险产品**"，
> 避免"存单变保单"式的误导。

**附加说明（按产品类型）**：

- **分红型 / 万能型 / 投连型** → 必须明确说明**保单利益的不确定性**，
  并按《一年期以上人身保险产品信息披露规则》进行保单利益演示
- **健康保险** → 说明等待期起算时间及影响、免赔额或赔付比例、
  合同指定医疗机构、**续保条件**、医疗费用补偿原则
- **以死亡为给付条件** → 须有被保险人（或其监护人）同意投保人为其
  订立保险合同并认可合同内容（投保人与被保险人为同一人的除外）

### 环节 4：如实告知

> 话术示例：
> "请问您对投保单中的询问事项是否都进行了如实告知？
> 投保单中的内容是否为您本人的真实意思表示？
> 需要提醒您，如果没有如实告知，可能影响将来的理赔。"

**要点**：确认 + 告知不如实告知的后果。健康告知尤其重要。

### 环节 5：以外利益

> 话术示例：
> "请问我有没有给您任何承诺，或者给您保险合同以外的利益？
> 比如返佣、礼品或其他好处？"

**要点**：由**投保人**确认销售人员未给予或承诺合同外利益。

## 三、特殊群体差异化处理

| 群体 | 要求 |
|---|---|
| **老年人** | 放慢语速、放大字号、重点条款反复确认；建议家属在场 |
| **残障人士** | 提供无障碍方式（手语、盲文、大字版） |
| **国家通用语言能力受限者** | 提供翻译或双语材料，确认理解 |

向 **60 周岁（含）以上**投保人销售保险期间超过一年的人身险，
是传统重点监管场景，务必完整录制。

## 四、录制后

- [ ] 视音频资料**不得剪辑**，保持真实、完整、连续
- [ ] 保存期限依产品年限为 **5–10 年**；发生纠纷的，纠纷解决后再保存 2 年
- [ ] 按公司要求上传归档
- [ ] 配合质检抽查

## 五、完整性自检表

录制完成后逐项核对：

- [ ] 销售人员身份证明已出示并告知机构名称
- [ ] 投保人身份证明已出示
- [ ] 被保险人身份证明已出示（如非同一人）
- [ ] 投保提示书已展示
- [ ] 产品条款已展示
- [ ] 免责条款书面说明已展示
- [ ] 明确告知是保险产品 + 承保机构名称
- [ ] 保险责任已说明
- [ ] 责任免除已说明
- [ ] 保险期间已说明
- [ ] 交费方式/金额/期间已说明
- [ ] 保单利益已说明
- [ ] 犹豫期起算、天数、权利已说明
- [ ] 犹豫期后退保费用与退保金计算已说明
- [ ] 如实告知已确认 + 后果已告知
- [ ] 以外利益已由投保人确认
- [ ] （分红/万能/投连）不确定性已说明
- [ ] （健康险）等待期/免赔额/续保条件已说明
- [ ] （以死亡为给付）被保险人同意已取得
- [ ] 视频显示录制时间
- [ ] 全程连续无剪辑

**任一项缺失，该笔双录存在合规瑕疵，须补录或说明。**
