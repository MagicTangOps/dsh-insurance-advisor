# 保单保全与理赔协同

展业第 8 阶段，也是加保与转介绍的入口。

## 一、保全（保单变更）

### 常见保全项目

| 项目 | 说明 | 注意 |
|---|---|---|
| 信息变更 | 地址、电话、银行卡 | 通常最简单 |
| 受益人变更 | 指定/变更身故受益人 | 须被保险人同意 |
| 保额变更 | 减保 | 减保可能影响保障充足性 |
| 险种转换 | 按合同约定 | 须重新核保的常见 |
| 保单复效 | 失效后 2 年内可申请 | **须补交保费及利息，可能重新健康告知** |
| 退保 | 犹豫期后按现金价值 | **损失须提前明确告知** |
| 保单贷款 | 按现金价值比例 | 有额度上限与利息 |

### 时效承诺

| 事项 | 时限 |
|---|---|
| 资料不全/不规范 | 收到申请起 **5 个工作日**内一次性通知补正 |
| 受理 | 资料齐全且符合约定起 **2 个工作日**内完成受理 |
| 处理完毕（不涉及缴费） | 同意保全起 **5 个工作日**内 |
| 处理完毕（涉及缴费） | 缴纳足额保费起 **5 个工作日**内 |
| 涉及体检 | 体检时间**不计入**上述期限 |

> 特殊情况无法按期完成的，须**及时说明原因并告知进度**。

### 关键提示

- 犹豫期后退保只退**现金价值**，早期退保损失可能很大
- **减保/退保前先评估保障缺口**，避免客户失去必要保障
- 复效须重新健康告知，健康已变化者可能无法复效

## 二、理赔协同

### 代理人角色

代理人不承担核赔责任，但承担**协助与沟通**：

1. 接到客户报案后，**及时告知索赔注意事项**
2. 指导客户准备索赔资料
3. 协助提交，跟踪进度
4. 结果解释与情绪安抚

### 时效承诺

| 事项 | 时限 |
|---|---|
| 核定 | 收到理赔申请起 **5 个工作日**内 |
| 情形复杂 | **30 日**内（合同另有约定除外） |

### 常见拒赔原因（提前预防）

| 原因 | 预防 |
|---|---|
| **未如实告知** | 投保时严格走健康告知，留存记录 |
| 等待期内出险 | 明确告知等待期 |
| 不属于保险责任 | 明确说明保险责任与责任免除 |
| 免责条款情形 | 双录时展示免责条款书面说明 |
| 未达赔付条件 | 说明免赔额、赔付比例 |

> 理赔纠纷大多可追溯到**投保环节的告知与说明不到位**。
> 这也是双录与如实告知的合规价值所在。

## 三、续期与回访

### 新单回访

- 一年期以上人身险新单，须在**犹豫期内 100% 回访**
- 回访四项：是否阅读并理解产品说明书/投保提示；是否知悉保险责任、
  责任免除、保险期间；是否知悉退保损失；期缴的缴费期间与频率

### 续期缴费

- 提前提醒客户缴费，避免保单失效
- 失效后在 **2 年内**可申请复效

### 犹豫期管理

- 起算日：**投保人签收保单回执之日**（电子签收按系统记录时间）
- 时长：一般 **10 日**（银保渠道 **15 日**），部分公司 20 天
- 犹豫期内退保：扣除不超过 **10 元**工本费外全额退还

## 四、加保与转介绍

服务是加保与转介绍的入口。建议在以下节点回访：

| 时点 | 动作 |
|---|---|
| 保单生效后 | 确认回执、说明犹豫期权利 |
| 犹豫期结束前 | 回访确认理解（**关键时点**） |
| 每年保单周年日 | 检视保障是否仍匹配当前家庭状况 |
| 家庭结构变化 | 结婚、生育、购房、收入显著变化 → 检视缺口 |
| 理赔后 | 检视其他成员的保障覆盖 |
| 满期/领取前 | 提前告知领取流程 |

> 加保前**同样要走适当性匹配**——客户风险承受能力或代理人授权
> 可能已变化，不得沿用旧结论。

## 五、服务自检清单

- [ ] 保全资料要求已一次性告知客户
- [ ] 退保/减保前已明确告知损失并评估保障缺口
- [ ] 复效客户已确认可重新健康告知
- [ ] 理赔资料清单已提供
- [ ] 时效承诺已向客户说明
- [ ] 回访记录已归档
- [ ] 加保前重新完成适当性匹配
