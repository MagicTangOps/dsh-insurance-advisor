# 保险计划书生成规范

计划书是展业的核心交付物。**结构必须完整，风险提示不可省略。**

## 前置条件（缺一不可）

出计划书前必须已完成：

1. **需求分析**（见 `insurance-needs-analysis`）—— 有需求分析报告
2. **适当性匹配** —— 产品分级与代理人授权、客户等级均已校验通过

> ⚠️ **若适当性校验未通过，不得出具该方案。**
> 这不是建议而是强制要求，详见 `insurance-compliance`。

## 标准结构

```
一、客户需求摘要
二、保障缺口分析
三、方案设计
四、保单利益演示
五、风险提示
六、免责声明
```

### 一、客户需求摘要

- 家庭结构（标注经济支柱）
- 年收入 / 负债 / 可承受保费区间
- 客户关注点与理财偏好
- 已有保障情况

### 二、保障缺口分析

按「家庭成员 × 险种」列表：

| 家庭成员 | 险种 | 应有保额 | 已有保障 | 缺口 |
|---|---|---|---|---|
| 本人（支柱） | 定期寿险 | … | 社保/团险 | … |

### 三、方案设计

逐产品说明：

- 产品名称与**产品分级（P1–P5）**
- 险种类型
- 保额 / 保险期间 / 交费期间 / 年交保费
- 该产品解决什么缺口
- **等待期、免赔额、续保条件**（健康险必填）

**保费合计**与占年收入比例（应 ≤ 20%）。

### 四、保单利益演示

**必须**符合《一年期以上人身保险产品信息披露规则》：

- 分红型 / 万能型 / 投连型：**必须区分保证利益与非保证利益**，
  并显著标注"非保证利益仅供参考，不代表实际收益"
- 演示须使用监管规定的假设（不得自行调高）
- 投连型须说明投资账户风险等级（R1–R5）与客户风险承受能力的匹配

### 五、风险提示（不可省略，不可弱化）

固定包含：

1. 本计划书为**建议方案**，具体以保险合同条款为准
2. 分红/万能/投连产品的**保单利益具有不确定性**，
   历史收益不代表未来表现，**最低保证利率之上的利益承诺无效**
3. 犹豫期说明：起算日（**以回执签收日为准**）、天数、期内权利
4. 犹豫期后退保可能产生**损失**，退保金按合同现金价值计算
5. 投保时须**如实告知**，否则可能影响理赔
6. 健康险的等待期、免赔额、赔付比例、指定医疗机构、续保条件

### 六、免责声明

- 本方案基于客户提供的信息编制，信息不实可能影响方案适用性
- 方案不构成投资收益承诺
- 最终承保结论以保险公司核保结果为准

## 输出格式

- 用 `skill-office` 生成 **Word 或 PowerPoint**
- 交付时用 `office-to-pdf` 转 PDF（便于客户阅读与留档）
- 用 `present` 向代理人展示交付物卡片

## 常见错误（务必避免）

| 错误 | 后果 |
|---|---|
| 跳过需求分析直接推荐产品 | 违反适当性管理"了解你的客户"要求 |
| 承诺保证收益 | **监管红线** |
| 只演示高档收益 | 构成销售误导 |
| 省略风险提示 | 合规瑕疵 |
| 健康险不说明续保条件 | 后期纠纷高发点 |
| 保费超年收入 20% | 缴费压力大，易中途退保 |
| 先给孩子买、支柱裸奔 | 保障顺序错配 |

## 检查清单

- [ ] 保费合计 ≤ 年收入 20%
- [ ] 非保证利益已显著标注
- [ ] 风险提示六项齐全
