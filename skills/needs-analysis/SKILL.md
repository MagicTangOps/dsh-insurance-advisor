# 保险需求分析（KYC）

展业第 3 阶段。产出**需求分析报告**，是后续方案设计的唯一依据。
**不要跳过这一步直接推荐产品**——这是适当性管理"了解你的客户"的法定要求。

## 四步流程

### 第 1 步：收集基础信息

必收字段（缺失就用 `ask_user_question` 补齐，**不要臆测**）：

| 字段 | 说明 |
|---|---|
| 年龄 / 性别 | 影响费率与投保年龄上限 |
| 职业 | 职业类别影响意外险可保性与费率 |
| 家庭成员结构 | 配偶、子女、父母；各人的收入与依赖关系 |
| **是否为家庭经济支柱** | 决定保障优先级 |
| 收入 / 支出 | 年收入、年支出、负债（房贷、车贷） |
| 已有保障 | 社保、企业团险、已有商业保单（保额、险种） |
| 健康状况 | 体检异常、既往病史 —— 影响核保，**必须如实告知** |
| 理财偏好 | 风险承受意愿（决定是否涉及 P4/P5 产品） |

### 第 2 步：识别经济支柱

家庭保障的优先级排序原则：**先支柱、后其他；先大人、后小孩**。

> 常见误区：给孩子买一堆，支柱裸奔。若客户提出先给孩子配置，
> 应说明支柱倒下对家庭财务的冲击最大，建议调整顺序。

### 第 3 步：评估经济承受力

用三项指标：

- **收入支出比** —— 判断可支配结余
- **资产负债率** —— 负债越高，定期寿险需求越大
- **投资结构** —— 判断风险承受能力

**保费预算区间**：

| 区间 | 评价 |
|---|---|
| 年收入 10% | 双十原则下限，最稳妥 |
| 年收入 10%–15% | 较科学的常见区间 |
| 年收入 15%–20% | 上限，需谨慎 |
| **> 20%** | **不建议**，缴费压力会导致中途退保损失 |

### 第 4 步：检验保障缺口

**双十原则**（初筛工具）：
```
保额 ≈ 年收入 × 10
保费 ≈ 年收入 × 10%
```

**缺口计算**：
```
保障缺口 = 理论保额 − 已有保障（社保 + 企业团险 + 已有商保）
```

**必须向客户说明双十原则的局限**：
1. 未考虑不同家庭的财务差异与实际需求
2. 对不同险种组合无法精准搭配
3. 未考虑负债、子女教育、赡养父母等刚性支出

因此双十原则是**起点而非结论**。更严谨的做法是按**需求法**：
```
寿险保额 = 负债 + 子女教育金 + 家庭生活开支 × 支撑年数 − 已有资产 − 已有保障
```

## 按险种的需求触发条件

| 险种 | 触发条件 |
|---|---|
| 医疗险 | 几乎所有家庭；关注免赔额、续保条件、指定医疗机构 |
| 重疾险 | 有收入贡献者；保额建议覆盖 3–5 年收入 + 康复费用 |
| 意外险 | 有出行/职业风险；注意职业类别限制 |
| 定期寿险 | **有负债或家庭依赖者**（房贷、子女未成年） |
| 年金/增额终身寿 | 养老储备、子女教育金、资产传承；**属长期资金规划** |
| 高端医疗/重疾海外 | 高净值客户，需评估真实就医需求 |

## 输出格式

产出需求分析报告，至少包含：

1. **家庭结构图** —— 标注经济支柱
2. **财务摘要** —— 年收入、负债、可承受保费区间
3. **保障缺口表** —— 按家庭成员 × 险种列出「应有 / 已有 / 缺口」
4. **健康告知要点** —— 已知异常记录（提醒投保时如实告知）
5. **下一步** —— 进入方案设计，并注明需匹配的适当性等级

## 交接约束

需求分析完成后，**必须**先做适当性匹配再出方案：

- 依据客户风险承受能力判定客户等级
- 依据拟推荐产品确定产品分级（P1–P5）
- 校验代理人当前能力等级是否有权销售

**若产品分级超出代理人授权，不得出具该方案**，应改推授权范围内的产品，
并说明原因。相关判定调用适当性工具完成，不要自行推断。
