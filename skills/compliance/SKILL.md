# 保险销售合规要点速查

> 监管持续更新。**引用具体条款前先用联网搜索核对最新版本**，
> 本文件提供框架与检查表，不能替代对现行有效法规的查证。

## 一、产品适当性管理（最重要）

**《保险产品适当性管理自律规范》** —— 中保协发布，**2026-07-01 施行**。

### 产品分级（人身险）

```
P1 → P2 → P3 → P4 → P5     复杂程度由低到高
```

- **P4 / P5**：投连型保险、变额年金保险、非保本型商业养老金等
  **利益浮动**产品
- P4/P5 须对产品或其投资账户划分风险等级：

| 等级 | 含义 |
|---|---|
| R1 | 低风险 —— 收益/净值波动小，本金损失可能性低 |
| R2 | 中低风险 |
| R3 | 中风险 |
| R4 | 中高风险 |
| R5 | 高风险 —— 收益波动大，本金损失可能性高 |

### 销售人员能力等级（四级）

| 能力等级 | 授权销售范围 |
|---|---|
| 不作要求 | P1 |
| 四级 | P1、P2 |
| 三级 | P1、P2、P3 |
| 二级 | P1、P2、P3、P4 |
| **一级** | **全部（含 P5）** |

**组合销售**（两种及以上产品）：按 **"从高不从低"** 原则确定授权。
即组合中最高分级决定所需等级。

销售**专属普惠产品**：可视情况放宽能力等级要求。

### 三位一体

```
产品分级 ↔ 人员分级 ↔ 客户分级
```
核心原则：**"适当的产品、适当的渠道、适合的客户"**（卖者尽责）

### 佣金追索扣回

因销售人员违法违规导致经济损失的，机构可**追索扣回**已发佣金薪酬。

## 二、销售行为可回溯（"双录"）

依据《保险销售行为可回溯管理暂行办法》（2017），2026 年多地大幅细化。

**适用范围**：向自然人销售**保险期间超过一年**的人身险，
或保险期间不超过一年但**保证续保**的产品。

**排除**：电话销售、互联网保险、自助终端投保及特定豁免产品。

**地方差异**（务必按展业地执行）：

| 地区 | 要点 |
|---|---|
| 山西 | 2027-04-01 起实施，有过渡期 |
| 新疆 | 全渠道覆盖，含专业中介与兼业代理 |
| 东莞 | 视听资料须真实、完整、连续，**不得任何剪辑**，须显示录制时间 |
| 福建 | 录制内容清单最详尽（见下） |

**福建局明确的五环节**（可作事实标准）：

1. **身份证明** —— 销售人员出示有效身份证明、告知所属机构名称；投保人/被保险人也须出示
2. **资料展示** —— 投保提示书、产品条款、产品说明书、免责条款书面说明
3. **产品说明** —— 承保机构、保险责任、责任免除、投保范围、保险期间、
   交费（方式/金额/期间）、保单利益、犹豫期（起算/天数/权利）、
   犹豫期后退保费用及退保金计算
4. **如实告知** —— 确认如实告知、系本人真实意思表示，告知不如实告知后果
5. **以外利益** —— 确认销售人员未给予或承诺给予**合同外利益**

**特殊群体**：老年人、残障人士、国家通用语言能力受限者
须实施**差异化**可回溯管理。

> 详细录制话术与定制化清单见 `insurance-dual-record` 技能。

## 三、犹豫期与新单回访

- 犹豫期：收到保单并**书面签收之日**起 **10 日**（银保渠道 **15 日**），
  部分公司延长至 **20 天**
- **起算以回执日期为准**；电子签收以系统记录时间为准；
  他人代收以实际取得并知悉之日为准
- 犹豫期内退保：扣除不超过 **10 元**工本费外**全额退还**，不得收取其他费用
- 一年期以上人身险新单，须在**犹豫期内 100% 回访**

**回访四项必备内容**：
1. 是否阅读并理解产品说明书与投保提示
2. 是否知悉保险责任、责任免除、保险期间
3. 是否知悉退保可能受到的损失
4. 期缴的，是否了解缴费期间与缴费频率

## 四、禁止行为（红线）

- ❌ 承诺**保证收益**（分红/万能/投连的历史收益不代表未来）
- ❌ 给予或承诺给予**合同外利益**（返佣、送礼）
- ❌ 以**其他金融产品名义**宣传销售保险（"存单变保单"）
- ❌ 混淆**保险与其他金融产品**的差别
- ⚠️ 必须说明**保单利益的不确定性**（分红/万能/投连强制）

## 五、个人代理人身份限制

- **仅限一家机构**执业登记，不得同时为多家代理
- **不得签发保单**
- **不得**办理企业财产险、团体人身险
- 业务范围：代理推销保险产品、代理收取保险费
- 佣金计税可扣除 **40% 展业成本**

## 六、报行合一

- 实际经营行为须与备案的**条款、费率、费用假设完全一致**
- 长期险销售渠道（如个人代理）**不能**与
  互联网代理、银邮代理、经纪代理**混同报送**

## 七、服务时效

| 事项 | 时限 |
|---|---|
| 投保资料有误/不完整 | 5 个工作日内一次性告知 |
| 无需体检且同意承保 | 15 个工作日内完成合同制作送达 |
| 需体检/生存调查 | 5 个工作日内告知；收到报告起 15 个工作日内告知核保结果 |
| 保全资料不全 | 5 个工作日内一次性通知补正 |
| 保全受理 | 2 个工作日内 |
| 保全处理 | 不涉缴费 5 工作日；涉缴费缴足起 5 工作日 |
| 理赔核定 | 5 个工作日内；复杂 30 日内 |

## 合规自检清单

出方案前逐项确认：

- [ ] 产品分级（P1–P5）已确定
- [ ] 代理人能力等级已核对，授权覆盖该产品
- [ ] 组合销售时按"从高不从低"校验
- [ ] P4/P5 产品已完成风险等级（R1–R5）匹配
- [ ] 客户风险评估已完成，且有留痕
- [ ] 保单利益不确定性已说明（如涉及分红/万能/投连）
- [ ] 健康险的等待期、免赔额、续保条件已说明
- [ ] 以死亡为给付条件的，被保险人同意已取得
- [ ] 双录清单已按产品类型与客户群体定制
- [ ] 展业地双录规则已确认
